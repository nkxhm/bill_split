# LineSplit

A browser-based telephone bill calculator. Split shared charges evenly, add individual extras, and copy each person's breakdown.

## Use

Open `index.html` in any modern browser. No installation or build step is required. Values are processed in the browser and are not uploaded or saved between visits.

Enter the full bill including taxes, fees, and extras. Add each person's individual extras. The remaining amount is split equally, with rounding pennies assigned in list order so the amounts reconcile exactly.

Supports USD, CAD, GBP, EUR, AUD, INR, and PHP currency formatting. This does not convert currencies.
